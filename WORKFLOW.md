# Lean production sequence

1. **Start.** Use the user's selected topic and separately supplied context. Create `runs/<slug>/`. Check required capabilities once. Record topic, source scope, style, timing basis and any missing capability in `run.json`. Do not select an unrelated topic or reproduce prior work.
2. **Research and write.** Browse actual primary passages and only necessary adjacent context. Make `sources.md`: concise Hindi/English context, claim-to-source links with passage locators, brief permitted quotations, uncertainties and interpretation boundaries. Write one complete spoken Hindi script in `script.json`, with stable line IDs. Do not invent the owner's beliefs. Avoid dialogue presented as exact quotation unless verified.
3. **Direct.** Use `storyboard.json` for distinct story jobs, script-line mappings, contiguous estimated timings, visual ideas, identity continuity and labels for metaphor. Store actual prompts/calls/repairs in one `generation-log.json`. Only include characters present in each shot. Prefer positive, specific pose/gesture/relationship instructions. Generate an identity anchor only when consistency actually needs one; then batch independent scene work when tools support it.
4. **Gate 1.** A reviewer checks the actual source evidence, exact current script and shot meaning together. Save concise findings/decision in `reviews/meaning-review.json`; bind to current script/board/source hashes. Correct affected claims only. Do not generate known misleading art.
5. **Generate and prepare.** Inspect actual style/identity references first. Generate finished `images/SH001.png`, etc. Review the sequence for new information, material treatment, gestures, identities and unsupported lore. Populate `mask-plan.json` with conservative normalized rectangles on the fitted 720×1280 image. Protect all people/animals/props needing stability; environmental effect zones must avoid them and the caption band. Rectangles are manually designed masks, not extracted editable body layers. Add optional local audio paths/licence evidence. Run prepare.py and the renderer's `--sheets` mode.
6. **Gate 2.** Independently inspect every actual image and the motion-zone sheet. Record concrete findings and current image hashes in `reviews/images-review.json` using the template. Repair blockers only; update affected masks/hashes and inspect changes. Never write PASS before inspection. Do not regenerate sound shots for optional cosmetics.
7. **Finish once.** Render through the reusable renderer. It produces captions, movie, sheets, decoded shot midpoints, meter (if audio exists) and export metadata. Inspect encoded motion across shot interiors and joins, not only midpoint stills. Extract additional short decoded samples as needed without re-encoding the movie. Check readable Hindi, causal continuity, consistent style/anatomy, safe effects, joins, correct dimensions/duration/frame count and no audio clipping. Fix a concrete failure, then rerender only if required.
8. **Gate 3 and deliver.** Record reviewer, target movie hash, performed samples, findings and decision in `reviews/encoded-review.json`. Make one `index.html` using review_page.py. It links the movie, exact script, source companion, scenes and subtitles. Update the same run ledger with final paths, actual calls/repairs, performed checks and remaining owner/listening/narration limitations. Deliver the MP4, master page and a short honest status. No repeated workspace handoffs, approval simulations, redundant ZIPs or copied media libraries.

## Minimum run files

Authored inputs: `run.json`, `sources.md`, `script.json`, `storyboard.json`, `mask-plan.json`, `generation-log.json`, real `images/*.png`, and three concise gate records. Audio, if used, adds its local files and licence evidence. Preparation and render outputs stay in the same run. Do not create extra variants or reports unless a concrete need arises.

The helper tools do not enforce every semantic gate. The assistant must perform the checks and record actual evidence. Hashes tie a review to bytes; they do not prove quality or independence.
